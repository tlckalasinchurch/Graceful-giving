# Grace Giving — Thai Glossary (DRAFT เพื่อ PO ตรวจ)

สถานะ: **ร่าง ยังไม่ได้รับอนุมัติ** (TBD-19/29) ศัพท์ที่ไม่ผ่านการอนุมัติห้ามขึ้นหน้าจอ · แก้ไข 2026-11-24
**ป้าย:** คอลัมน์ "ปัจจุบัน" = [V-src] อ่านจากซอร์ส (ไม่ใช่การดูหน้าจอจริง) · คอลัมน์ "ข้อเสนอ" = [P] · ช่องว่าง = คงเดิม · [NV] = ยังไม่ได้ตรวจ

**กติกา TBD-29 (PO):** ห้ามเปลี่ยนคำที่มีความหมายด้านการเงินหรือ Workflow โดยไม่มีหลักฐาน คอลัมน์ "ข้อเสนอ" ทั้งไฟล์จึงเป็น **ตัวเลือกที่ต้องทดสอบกับผู้ใช้จริง** ไม่ใช้บนหน้าจอจนกว่ามีหลักฐานและ PO อนุมัติ คำด้านการเงิน/Workflow (สถานะรอบนับ, ลงบัญชี, กระทบยอด, ผู้ลงนาม, เบิกเงิน) **คงเดิม**

หลัก: คำเดียวต่อแนวคิดทั้งระบบ · ไม่มีรหัสอังกฤษที่ผู้ใช้ไม่จำเป็นต้องรู้ · บอก "ใครต้องทำต่อ" เมื่อเป็นสถานะรอ · ผู้ใช้ทดสอบจริงต้องเข้าใจตรงกัน (TBD-18)

**ปัญหาที่พบ [V-src]:** Label กระจายอยู่หลายไฟล์ (`CommonUI.tsx`, `Approvals.tsx`, `Members.tsx`, `GivingInbox.tsx`, `shared/roles.ts`) จึงมีชื่อสองชุดสำหรับแนวคิดเดียว (ดูแถวที่มี ⚠)

## 8. ที่ยังไม่ได้ตรวจ

ชื่อปุ่มจริงทุกหน้า · ข้อความ Error/Toast ทั้งระบบ · ป้ายสถานะเบิกเงิน `disbursed`/`cancelled` · ที่ใช้ `labelWithCode` · ข้อความในหน้าหลังล็อกอินที่ไม่ได้อ่านซอร์ส · ความเข้าใจของผู้ใช้จริงต่อทุกคำ (ต้องทดสอบ)
