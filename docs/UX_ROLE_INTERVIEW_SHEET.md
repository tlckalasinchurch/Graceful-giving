# แบบสัมภาษณ์ผู้ใช้ตามบทบาท (Grace Giving)

ใช้เก็บหลักฐานก่อนปรับเมนู/หน้าแรก **ไม่ชี้นำ ไม่ช่วยกดระหว่างทำงาน** ถ้าผู้ใช้ติด ให้จดว่าติดตรงไหนแล้วถามว่า "คุณคาดว่าจะเจอมันที่ไหน"

เกณฑ์ที่ใช้ประเมิน: งานประจำหลักเสร็จภายใน **≤ 2 การกด** จากหน้าแรก โดยไม่ต้องมีใครสอน

## ข้อมูลทั่วไป (กรอกทุกคน)

| ช่อง | บันทึก |
|---|---|
| บทบาท | ☐ Super admin ☐ เหรัญญิก ☐ ศิษยาภิบาล ☐ ผู้นับซอง ☐ ผู้รับผิดชอบฝ่าย |
| ผู้ให้ข้อมูล (ชื่อเล่น/รหัส ไม่ต้องใส่ชื่อจริง) | |
| วันที่ | |
| อุปกรณ์ที่ใช้เป็นหลัก | ☐ มือถือ ☐ คอมพิวเตอร์ ☐ ทั้งสอง |
| คล่องเทคโนโลยีแค่ไหน (ผู้ให้ข้อมูลประเมินเอง) | ☐ ไม่คล่อง ☐ พอใช้ ☐ คล่อง |
| ใช้แอปมานานเท่าไร / บ่อยแค่ไหน | |

## ส่วนที่ 1 คำถามพูดคุย (ถามทุกบทบาท)

| # | คำถาม | คำตอบ (จดคำพูดจริง) |
|---|---|---|
| 1 | ครั้งล่าสุดที่เปิดแอป คุณเปิดมาเพื่อทำอะไร เล่าเป็นขั้นตอน | |
| 2 | งานที่ทำเป็นประจำมีอะไรบ้าง เรียงจากบ่อยที่สุด (ขอ 3-5 อย่าง) | |
| 3 | มีเมนูหรือปุ่มไหนที่เห็นแล้วไม่รู้ว่าคืออะไร หรือไม่เคยแตะเลย | |
| 4 | เคยหาอะไรไม่เจอ หรือกดผิดหน้าไหม ครั้งล่าสุดคือเรื่องอะไร | |
| 5 | งานนี้มีส่วนที่ทำนอกแอปด้วยไหม (LINE, กระดาษ, Excel) ส่วนไหน ทำไม | |
| 6 | ถ้าเปิดแอปมาแล้วเห็นได้เพียง 3 อย่างบนหน้าแรก อยากให้เป็นอะไร | |

## ส่วนที่ 2 ให้ลองทำงานจริง (สังเกต จับเวลา นับการกด)

ผู้ถามอ่านโจทย์ให้ฟังเท่านั้น เริ่มจากหน้าแรกทุกครั้ง **ใช้ข้อมูลทดสอบ/สภาพแวดล้อมที่ไม่กระทบข้อมูลจริง ห้ามกดยืนยันรายการที่สร้างธุรกรรมจริง**

| บทบาท | โจทย์ 1 | โจทย์ 2 |
|---|---|---|
| เหรัญญิก | "ลงยอดถวายวันอาทิตย์ที่ผ่านมา" (หยุดก่อนกดบันทึก) | "ดูว่ามีคำขอเบิกรอคุณอยู่ไหม" |
| ศิษยาภิบาล | "ดูว่าเดือนนี้ถวายและใช้จ่ายเท่าไร" | "หาคำขอที่รอคุณอนุมัติ" (หยุดก่อนกดอนุมัติ) |
| ผู้นับซอง | "เริ่มนับซองวันนี้" (หยุดก่อนกดเริ่ม) | "หาวิธีว่าต้องทำอะไรต่อหลังนับเสร็จ" |
| Super admin | "มีคนใหม่ล็อกอินเข้ามารออนุมัติ ไปอนุมัติ" (หยุดก่อนกดอนุมัติ) | "ดูภาพรวมของคริสตจักรเดือนนี้" |
| ผู้รับผิดชอบฝ่าย | "หาสมาชิกในฝ่ายของคุณ" | "ขอเบิกเงินสำหรับกิจกรรม" (หยุดก่อนกดส่ง) |
